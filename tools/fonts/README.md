# フォントについて

いずれも Google Fonts (https://github.com/google/fonts) の OFL (SIL Open Font License 1.1) フォントです。
各フォルダに同梱の `OFL.txt` がライセンス条文です。

- `NotoSerifJP-Variable.ttf`: Noto Serif JP (Variable, wght軸)。
  https://github.com/google/fonts/tree/main/ofl/notoserifjp から取得。現在は未使用(旧版の本文書体として同梱)。
- `BIZUDMincho/`: BIZ UD明朝。本文(扁平体)の既定書体。
  https://github.com/google/fonts/tree/main/ofl/bizudmincho から取得。
- `ShipporiMincho/`: しっぽり明朝。本文の書体案B、および見出し(太字 ExtraBold)の既定書体。
  https://github.com/google/fonts/tree/main/ofl/shipporimincho から取得。
- `ZenOldMincho/`: Zen Old Mincho (Black)。題字(コラム名)の既定書体。
  https://github.com/google/fonts/tree/main/ofl/zenoldmincho から取得。
